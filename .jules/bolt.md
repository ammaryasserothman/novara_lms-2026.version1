## 2024-03-12 - Prevent frequent recalculations in Dashboard
**Learning:** The application relies heavily on a global context (`useGlobal`). Derived states dependent on context values (like arrays in `courses` or `enrollments`) cause expensive nested loop recalculations during frequent context-driven re-renders. Furthermore, passing an inline object to the context provider makes it even worse.
**Action:** Aggressively wrap derived state calculations in `React.useMemo` with appropriate fallback/null checks to prevent expensive nested loop recalculations during frequent context-driven re-renders. Avoid memoizing functions that generate fresh arrays/objects on every call (like `getRecommendedCourses()`) using only the function reference as a dependency, instead, ensure the dependencies array includes the actual underlying data sources.
