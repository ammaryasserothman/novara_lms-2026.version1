## 2024-03-18 - Monolithic Context Derived State Optimization\n**Learning:** In monolithic React Contexts (like GlobalContext), unrelated state updates (e.g., adding a notification) trigger re-renders that recalculate all derived state. \n**Action:** Use `useMemo` to pre-compute expensive derived data (like recommendations or sorted lists) based only on their actual dependencies to avoid CPU overhead on every provider render.
