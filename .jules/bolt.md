## 2024-06-08 - O(N*D) Filter Optimization in Calendar View
**Learning:** Found an O(N*D) performance bottleneck in Calendar components where an array filter runs repeatedly for every day rendered inside the loop, causing redundant O(N) filtering. A standalone script benchmared this overhead showing ~600ms vs ~60ms using a map.
**Action:** Always pre-group array events using a Map keyed by the loop variable (e.g., day) outside of rendering loops to convert lookups from O(N) list scans to O(1) Map retrievals, significantly reducing calculation overhead.
## 2024-06-08 - Fixing React Reference Stability
**Learning:** Learned that if `React.useMemo` depends on an array generated by `.filter()` inside the render function (like `filteredEvents`), the `useMemo` block will re-run on every render because `.filter()` creates a new array reference each time. This defeats caching.
**Action:** Always make `React.useMemo` depend on primitive state values (e.g., `filter`) instead of derived arrays, and apply the filtering logic within the $O(N)$ loop of the `useMemo` block.
