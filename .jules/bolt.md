
## 2024-03-11 - Aggressively Memoizing Derived Context State | **Learning:** Derived states (like filtered arrays and recommendations) heavily dependent on frequently updating context values (like `useGlobal`) cause expensive recalculations on every render. Because React hooks must be called before any early returns, safety checks (e.g. `if (!user) return null;`) must be brought *inside* the `useMemo` hooks. | **Action:** Always wrap derived array operations originating from context in `React.useMemo`. Apply safety checks inside the memoized callback to prevent crashes while adhering to the Rules of Hooks. Suppress exhaustive-deps for context methods when they generate fresh objects and rely on context data instead.
