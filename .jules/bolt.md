## 2024-10-24 - Memoize GlobalContext value
**Learning:** Found a specific anti-pattern in `GlobalContext` where a large object literal containing many state values (like `enrollments` and `notifications`) and unmemoized functions was passed directly to the context `Provider`'s `value` prop. This was causing widespread, unnecessary re-renders across all subscribing components whenever any piece of state updated. Initially, I attempted to memoize the context value while ignoring the function dependencies (via eslint-disable), which is an anti-pattern that leads to stale closures.
**Action:** When implementing or modifying complex React Contexts in this codebase, always memoize the context `value` object using `React.useMemo`. Crucially, to properly prevent unnecessary re-renders without risking stale closures, you must first wrap all context functions (actions and getters) in `React.useCallback`, providing them with their proper dependency arrays (e.g., `[enrollments, courses]`). Then, include both the state variables and these memoized functions in the `useMemo` dependency array for the context `value`. This correctly prevents both unnecessary re-renders and excessive recalculations while maintaining safety.
