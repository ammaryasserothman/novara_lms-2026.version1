## 2024-05-14 - Global Context & Derived State Bottlenecks
**Learning:** In React applications relying heavily on a single massive global context (like `GlobalContext` containing courses, enrollments, AND notifications), *any* state change (e.g., adding a notification) causes all consuming components to re-render. If consuming components (like `Dashboard`) calculate derived state (e.g., filtering `courses` by `enrollments` status using `Object.keys().filter().map()`) in the render body, these O(N) operations run unnecessarily on every global event.
**Action:** Aggressively memoize expensive array/object derivations with `React.useMemo` in components that consume wide-reaching global contexts. Ensure dependencies are exact to prevent unnecessary recalculations, while also strictly following the Rules of Hooks by moving early returns (like auth checks) below all `useMemo` hooks.
