## 2026-03-20 - Optimize GlobalContext Rendering and Computations
**Learning:** The application's monolithic `GlobalContext` acts as a central data store for core entities (courses, enrollments, notifications), meaning any localized state update triggers widespread re-renders for all context subscribers. Furthermore, functions like `getRecommendedCourses` were returning fresh arrays on every render, bypassing React's dependency tracking and compounding the issue.
**Action:** When working with centralized React Contexts, strictly wrap context action functions in `useCallback`, pre-compute derived state via `useMemo` before returning it via a `useCallback` getter to preserve API interfaces, and always wrap the entire context provider `value` in `useMemo` to prevent cascading re-renders across the app.
