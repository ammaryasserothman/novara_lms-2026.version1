## 2024-10-24 - Calendar Grid Render Bottleneck
**Learning:** Rendering calendar grids with nested O(N) array filters per day (e.g., iterating through a month of 31 days and filtering the events array for each day inside the render block) causes severe performance degradation as the event list scales. This creates an O(N*D) overhead directly tied to React's render loop, leading to blocked main threads and sluggish UI updates when navigating months or applying filters.
**Action:** When mapping relational or contextual data (like events to specific days) within a loop, extract the O(N) filtering logic outside the render loop into a single `useMemo` block. Pre-group the data using a `Map` (e.g., keyed by day or ID) so that the inner loop retrieval becomes an O(1) map lookup. This reduces the algorithmic complexity from O(N*D) to O(N + D).
