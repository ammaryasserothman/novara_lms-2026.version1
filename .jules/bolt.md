## 2024-05-24 - Aggressive Memoization of Context-Derived States
**Learning:** In applications relying heavily on a global context (like `useGlobal`), derived states dependent on context values (like arrays in `courses` or `enrollments`) can cause significant performance bottlenecks if recalculated on every render. If these recalculations involve loops, filters, or map operations, they are especially costly during frequent context-driven re-renders.
**Action:** Aggressively wrap computationally heavy derived states in `React.useMemo`. However, to adhere to React's Rules of Hooks while supporting early returns (e.g., `if (!user) return null;`), make sure the `useMemo` hooks run unconditionally, and include safety checks (like `if (!user || !enrollments) return fallbackValue;`) inside the `useMemo` callback itself to prevent runtime crashes. Additionally, when dealing with functions that generate fresh arrays/objects on every call (like `getRecommendedCourses()`), ensure the dependencies array includes the actual underlying data sources (e.g., `courses`, `enrollments`) rather than just the function reference to ensure proper dependency tracking and invalidation.
