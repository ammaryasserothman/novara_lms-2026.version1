## 2024-03-03 - Context-driven Re-render Anti-Pattern
**Learning:** The application heavily relies on `useGlobal` which causes frequent re-renders across consumers when any context state changes. Derived state calculations in components like `Dashboard` (e.g., filtering courses, finding active enrollments) run on every render if not memoized, causing O(N) operations to run repeatedly. Early returns before hooks (like `if (!user) return null;`) also cause hook sequence violations when adding `useMemo`, requiring structural shifts.
**Action:** Aggressively wrap derived arrays and objects in `React.useMemo` within components consuming `useGlobal`. Move early returns strictly below all hooks. For functions like `getRecommendedCourses()` that return fresh arrays but don't take arguments, omit the function reference from the dependency array and depend directly on the context states (`enrollments`, `courses`) to prevent stale data while avoiding useless recalculations.
