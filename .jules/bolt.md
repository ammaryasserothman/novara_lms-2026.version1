## 2024-05-19 - Centralized Context Re-renders
**Learning:** In a heavily-context-dependent React application (like Novara LMS using `GlobalContext`), an unmemoized context `value` prop paired with unmemoized action and getter functions causes cascading, application-wide re-renders on any state change. Additionally, computing complex state derivates (like `getRecommendedCourses`) purely in a getter function means it's recalculated on every call by every subscriber during these re-renders.
**Action:** Always wrap Context provider `value` objects in `useMemo`. Ensure all functions exported by the context are wrapped in `useCallback`. For complex derived state accessed via getter functions, pre-compute the result using `useMemo` and return the memoized value from a `useCallback` getter to preserve the existing function API without redundant calculations.
