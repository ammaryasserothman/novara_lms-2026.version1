## 2025-04-08 - Array allocation bottleneck in LessonPage
**Learning:** Found an anti-pattern in `LessonPage` where nested `course.syllabus` arrays were repeatedly flattened on every render using `flatMap()`, both directly inside render calculations and implicitly within UI event handlers like button clicks and disabled states. Because `flatMap` generates intermediate array objects and does not break early, this triggered severe O(N*M) time and space overhead per render.
**Action:** Replaced repetitive array flattening and searching with a single-pass iteration inside `React.useMemo`. Calculate required states (indices, flat array, current lesson) together to change complexity from O(N*M) repeated ~8 times per render to O(N) single-pass. Added logic to preserve types appropriately.
