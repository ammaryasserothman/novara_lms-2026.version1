## 2026-04-18 - Avoid multiple flatMap traversals in React components\n**Learning:** The codebase repeatedly uses `flatMap` inside `LessonPage` and `GlobalContext` to calculate sequential item relationships. This causes O(N) array allocation on every render and button click.\n**Action:** Use nested `for...of` loops to calculate relationships without intermediate arrays, or use `React.useMemo` to prevent re-calculation. For next/prev lessons, calculate them simultaneously in one pass.
