## 2024-03-22 - Repeated Array Instantiation in Renders (flatMap)
**Learning:** Found multiple instances where `course.syllabus.flatMap(m => m.lessons)` was called inline during renders and inside button event handlers (`onClick`, `disabled` props). This causes an O(N) array allocation and traversal on every render and re-evaluation. While not a massive bottleneck for small datasets, it scales poorly as course sizes increase and causes unnecessary GC pressure. Using `flatMap` also has performance implications compared to a nested loop, but memoizing the flatMap outcome is a quick, readable, and effective optimization for React renders.
**Action:** When deriving flattened arrays from nested state (like syllabus -> lessons), always memoize the derived array with `useMemo` so the reference remains stable across renders and computations are performed only when the underlying data changes.
