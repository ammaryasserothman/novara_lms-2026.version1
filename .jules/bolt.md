## 2024-05-18 - Binding unstable context functions to underlying data dependencies
**Learning:** Functions provided by context that return fresh references (e.g. newly created arrays) on every call can cause unnecessary recalculations or infinite re-renders when used directly as dependencies in `useMemo` or `useEffect`. Standard dependency tracking relies on object reference equality, which is bypassed if a context function inherently generates fresh objects.
**Action:** When memoizing derived state that depends on such context functions, ensure the dependencies array includes the actual underlying data sources (e.g. `courses`, `enrollments`) rather than just the function reference, and wrap the data transformation in `useMemo` to preserve reference equality across renders unless the underlying data changes.
