## 2024-11-20 - Array Processing Bottlenecks in Kanban Views
**Learning:** In Kanban-style React views with multiple columns matching different statuses (e.g., AssignmentsPage), developers often use repeated `.filter(item => item.status === 'X')` calls inline. If a dashboard renders N assignments across C columns, this degrades performance to O(C * N) filtering checks on *every* render cycle, compounded by `.length` and `.map` calls.
**Action:** When identifying identical array sources being parsed multiple times for grouped UI views, replace the multiple `filter` passes with a single `Array.prototype.reduce` operation inside a `React.useMemo` to group the collection into an object index. This shifts the complexity to an optimal O(N) allocation and avoids continuous recalculations during React state updates.
