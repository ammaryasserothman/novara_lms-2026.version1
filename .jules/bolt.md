## 2024-05-17 - O(N*M) Array Traversal Bottleneck in React Context
**Learning:** Found a critical performance bottleneck in `GlobalContext` where `getNextLesson` was repeatedly using `flatMap` to create a new array of all lessons, and then calling `.includes()` on the array of completed lessons inside a `.find()` loop. This resulted in O(N*M) time complexity and unnecessary memory allocations on every render for any component consuming this context. A similar issue was present in `LessonPage` where `flatMap` was called four times inline to calculate previous/next lesson IDs.
**Action:** Replace nested array lookups (`.includes` inside loops) with a `Set` for O(1) lookups. Extract repeated inline calculations into a single O(N) pass using nested `for...of` loops wrapped in `useMemo` to prevent redundant array allocations during React renders.
