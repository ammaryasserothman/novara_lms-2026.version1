## 2024-03-09 - Memoizing Global Context Dependencies Safely
**Learning:** Derived state in components that heavily rely on `useGlobal` (like `Dashboard.tsx`) needs aggressive memoization (`useMemo`) to prevent expensive recalculations during context updates. When doing so, early returns for unauthenticated states must be moved below the `useMemo` block to follow React's Rules of Hooks. A safety check (`if (!user || !data) return fallback;`) must be added inside the `useMemo` callback to prevent runtime crashes. Additionally, functions like `getRecommendedCourses()` that generate new arrays every call should be omitted from the dependency array (using `// eslint-disable-next-line react-hooks/exhaustive-deps`) in favor of their underlying data sources (like `courses` and `enrollments`).
**Action:** Next time I optimize a component deeply integrated with context, I will wrap all derived data in `useMemo`, ensure early returns are placed after the hook, implement safety checks inside the memoized callback, and strictly manage the dependency array to include raw data sources instead of dynamic functions.
