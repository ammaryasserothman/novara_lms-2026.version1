## 2024-05-02 - O(N) Array Allocation Avoidance via Single-pass Iteration after Early Returns
**Learning:** Using chained array methods like `.filter().map().slice()` along with `Object.keys()` to extract components of lists inside a React render function incurs multiple O(N) array allocation overheads. When early returns (e.g., `if (!user) return null;`) prevent wrapping this derivation inside `React.useMemo` due to the Rules of Hooks, using a synchronous single-pass `for...in` loop avoids this overhead cleanly without introducing complex context setups.
**Action:** When filtering or mapping data from objects/arrays inside React components that cannot utilize `useMemo`, apply standard JS synchronous `for...in` or `for...of` iteration blocks to simultaneously derive variables and minimize redundant loop and array memory allocation.
