## 2024-05-24 - Derived State Recalculation Bottleneck
**Learning:** The application architecture relies heavily on GlobalContext. Components like Dashboard derived multiple nested states (active courses, mapping progress, and generating recommendations) directly in the render body, which caused expensive recalculations on every context update.
**Action:** Aggressively wrap derived state dependent on context arrays in `React.useMemo`. Ensure the dependency array includes the actual underlying data sources (e.g., `courses`, `enrollments`) rather than function references, and safely suppress lint warnings for omitted function references like `getRecommendedCourses()` using `// eslint-disable-next-line react-hooks/exhaustive-deps`. Ensure early returns are strictly after hook calls to abide by React's Rules of Hooks.
