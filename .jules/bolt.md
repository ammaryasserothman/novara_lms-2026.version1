## 2024-05-24 - [Optimize getRecommendedCourses]
**Learning:** The previous implementation of `getRecommendedCourses` in GlobalContext.tsx iterated over courses and performed an O(N*M) lookup inside the `.sort` function which is O(N log N). Since `getRecommendedCourses` is a function inside a React context, it triggers this calculation on every render for any component that calls it. By pre-calculating an O(1) lookup map using `Set` for `enrolledIds` and `userCategories` and iterating through the courses array a single time, we reduced the complexity from O(N*M) and O(N log N) to O(N).
**Action:** When performing searches or filtering over arrays nested within React Contexts, optimize O(N*M) lookups with `Map` or `Set` to establish O(1) time complexity. Ensure the resulting recommendation is memoized using `useMemo` and its getter uses `useCallback` to prevent cascading re-renders and preserve existing function signatures.
