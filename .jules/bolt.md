## 2025-03-02 - Memoizing Context-Derived States in Dashboard
**Learning:** The application heavily relies on global context (`useGlobal`). Derived states that calculate things like `activeCourse` and `otherEnrolledCourses` by mapping, finding, or filtering over context arrays (`courses`, `enrollments`) cause expensive recalculations on every context-driven re-render. Additionally, moving these calculations into hooks like `useMemo` means we must be careful with early returns (e.g., `if (!user) return null;`) to not violate React's Rules of Hooks.
**Action:** Aggressively wrap context-dependent derived states (arrays/objects filtering or matching) in `useMemo` hooks. Ensure that any early returns are strictly placed after all hook calls to prevent linter and runtime errors.
