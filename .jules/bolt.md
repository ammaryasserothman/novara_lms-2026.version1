## 2024-05-24 - Array Filtering in Calendar View Render Loops
**Learning:** Performing multiple $O(N)$ array filter operations inside an $O(D)$ render loop (where $D$ is the number of days in a month) leads to an inefficient $O(N \times D)$ rendering profile. For a calendar view rendering 31 days with 5,000 events, this redundant filtering took ~91ms and blocked the main thread.
**Action:** When mapping or filtering collections by a temporal grouping (like days) during a render loop, wrap the collection in a `useMemo` block that pre-groups the items into a `Map` keyed by the grouping factor. This shifts the algorithmic complexity to an $O(N)$ preprocessing step with an $O(1)$ lookup per rendered item, drastically improving execution time (from ~91ms to ~3.9ms in this scenario) and avoiding main thread blocking.
