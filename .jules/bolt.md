## 2024-10-24 - Calendar Component O(N*D) Render Loop Bottlenecks
**Learning:** In calendar components, filtering the global events array inside the render loop for every single day of the month creates an expensive O(N*D) performance bottleneck, where N is the number of events and D is the days in the view (e.g., 31). This issue scales poorly with the number of events, taking significantly more CPU time on each render.
**Action:** When calculating daily events for calendar grids, pre-group the filtered events into a Map using `useMemo` keyed by the day. This reduces the time complexity from an O(N*D) nested loop down to an O(N) map population phase followed by an O(1) retrieval phase per day. Also ensure the fallback empty array is extracted to a static constant to maintain React reference stability.
