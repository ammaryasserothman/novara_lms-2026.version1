## 2023-10-27 - Memoization of Derived Data and Single Pass Optimization
**Learning:** In functional React components, chained `.map()` and `.filter()` operations on arrays trigger O(N) operations on every render. When wrapping logic in `useMemo`, ensure the dependency arrays accurately reflect the scope of the operations. If generation logic is combined with filtering logic in a single `useMemo` block that depends on a `filter` state, the entire expensive generation block re-runs every time the filter changes.
**Action:** Always split memoization into multiple steps: one `useMemo` block to compute base derivations (dependent only on raw data), and a separate `useMemo` block for state-dependent transformations (like filtering or sorting). Additionally, extract loop logic into a single pass block where possible to minimize array iterations.
